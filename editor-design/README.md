# 工事連絡・進捗管理の編集レイアウト

Pleasanter 1.4.23.3 の編集画面に登録する JavaScript と CSS です。タイトル直下に対応状況を置き、グリッドサービスGを淡い黄、配電建設Gを淡い青緑のカードにまとめます。入力欄は編集領域の幅に応じて3列、2列、1列に切り替わり、連絡記録は最大2列です。

## 登録

1. 対象テーブルの設定を保存してから、［管理］→［テーブルの管理］→［エディタ］で既存項目を確認します。[項目対応表](field-mapping.md)の25項目を照合し、不足分だけ未使用枠に追加します。標準タブの直下にある対象項目に対応します。既存セクションや別タブにある場合は、その配置に依存する既存CSを確認してから標準タブへの集約可否を判断してください。
2. [editor-layout.js](editor-layout.js) 冒頭で、テーブルに合わせて `prefix` と `columns` を設定します。DOM上の内部名が必要な場合は、編集画面で [inspect-editor-dom.js](inspect-editor-dom.js) を開発者ツールのコンソールから実行します。出力は項目ラベルとDOM構造です。
3. テーブルの管理の［スタイル］に [editor-layout.css](editor-layout.css) の本文、［スクリプト］に設定済みJavaScriptの本文を追加します。まず出力先「編集」で新規・既存レコードを確認します。一覧からAjaxで開く運用でファイルが読み込まれない場合は出力先「全て」を選択して動作確認します。CSSはスクリプトが付けた編集領域のクラス内に限定され、対象テーブルの［スクリプト］に直接登録してください。全テーブル共通の拡張スクリプトとして登録すると、同じ項目構成の別テーブルにも適用されます。
4. 下のチェックを検証用レコードで実施します。切り戻しは追加したスクリプトとスタイルを無効化し、ページを再読込します。

既存の入力ラッパーを同じフォーム内で移動します。Pleasanterの見出し、作成・更新ボタン、チェック欄のラベル、Markdownの編集切替と画像操作は標準部品を使います。添付サンプルの「転記」が実環境のCSで実装済みなら操作を確認してください。ボタンが対象ラッパーの外にある場合は移動対象にならないため、実DOMに合わせた調整が必要です。

項目不足や重複、未対応の配置を検知すると標準レイアウトのままです。コンソールの `[編集レイアウト]` を確認してください。「読み込みました」が出なければ登録内容や出力先を確認します。「適用を見送りました」の後には該当項目と理由が表示されます。「適用済み」が出ても見た目が変わらなければスタイルの登録を確認してください。DOM再描画はMutationObserverで検知し、`$p.events.on_editor_load` の代入は行いません。監視停止は再描画への追従だけを止めます。表示を元に戻す場合はスクリプトを無効化して再読込してください。既存CSが親子関係や隣接関係で項目を検索する場合は、対象セレクターも確認してください。

## 動作確認

|操作|期待する結果|
|---|---|
|新規・既存レコードを開く|タイトル直下に対応状況。両グループに安全処置の見出し。連絡記録の工事日と工事完了を区別できる|
|Edgeの幅を変更|通常欄は3→2→1列、連絡記録は2→1列。ラベル・入力・画像操作が重ならない|
|入力・Tab・Enter|表示順に操作でき、長文欄のEnterで改行できる|
|未入力や不正値を保存|既存のエラーが対象欄に表示される|
|選択・チェック・日付ピッカー|設定済みの選択肢を選べ、チェックと日付の変更が反映される|
|作成・更新・再読込|選択肢、日付、チェック、長文4欄が保存され、再表示でもカードが1組だけ表示される|
|長文の画像追加・添付欄|正常なPNGで追加、プレビュー、保存後の表示、削除ができる|
|権限・ステータス別の表示|非表示・読取専用・必須・自動ポストバックが従来どおり動く|
|前後レコード、ダイアログ、一覧、別テーブル|利用中の遷移で再描画後も配置が正しく、対象外にカードが出ない|
|既存CSの操作|転記などの既存ボタンが動き、コンソールに新しいエラーが出ない|

## 検証結果

Dockerの1.4.23.3の専用記録テーブル（SiteId 847840）で、25項目の実HTMLとカード表示、必須チェック、選択欄、チェック欄、日付ピッカーでの日付選択、長文4欄の入力と改行を確認しました。簡略版は同じ実HTMLを使ったDOM検証6件が通過しました。項目単体の置換と編集タブ全体の置換はDOMテストで再現し、実ブラウザでは再試験していません。画像追加は破損したテストPNGでサーバーエラーになり、正常な画像での再試験は中断されました。保存・再読込、Edgeでの幅別表示、別環境の既存CSとの共存は上の表で確認してください。

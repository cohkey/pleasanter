# 編集画面レイアウト

## 組織単位

```text
対象

対象組織 [営業部              ]  組織キー [DEPT-SALES       ]  [x] 有効

権限設定

権限                  適用範囲
------------------------------------------------
アプリ利用            [全社員（派遣社員を含む）]
レコード作成          [通常社員のみ            ]
レコード更新          [全社員（派遣社員を含む）]
レコード削除          [許可しない              ]
```

## ユーザ単位

```text
対象

対象ユーザ [山田 太郎          ]  ユーザキー [user-yamada      ]  [x] 有効

ユーザ個別設定

権限                  個別設定
------------------------------------------------
アプリ利用            [組織設定に従う          ]
レコード作成          [このユーザを拒否        ]
レコード更新          [組織設定に従う          ]
レコード削除          [組織設定に従う          ]
```

## レスポンシブ動作

- 対象欄は最大幅 `1040px` とし、広い画面でも入力欄を伸ばしすぎません。
- 権限表は最大幅 `720px` とし、左寄せで表示します。
- 画面幅が `760px` 以下の場合、対象欄のラベルを入力欄の上へ戻します。
- 権限表は最小幅を維持し、必要な場合だけ横スクロールします。

## ラベルの扱い

Pleasanter の `LabelText` と `GridLabelText` は権限ごとに固有名を維持します。
画面では表の列見出しに「適用範囲」または「個別設定」を表示するため、
各セレクトボックス内の重複ラベルだけ CSS で非表示にします。

これにより、編集画面の重複を減らしつつ、CSV エクスポート・インポート時の
項目識別を維持します。
